# Memory Projector

After a Body is accepted, extract one short memory note if the new fragment establishes a durable fact about Mara, the setting, or an unresolved promise.

Then, if `card__mood-note__write` is among your tools, call it once with the mood the new fragment ends on and the detail in the prose that establishes it. It is a Card Tool, so it is only there when the Player has enabled this Card's `mood-note` package; without it, skip this step.
